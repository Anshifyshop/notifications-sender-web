Send notification to players

Goes to phones that opened the new APK.

How to use / setup (tap)
  1. Make a token (log in as Anshifyshop):
    https://github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → racers-push.
  3. Permissions → Repository → Add permissions → Actions: Read and write.
  4. Tap Generate token, copy it, then tap Paste below. It is saved on this phone.
  5. Tap Test token. Green = ready.
  6. Write title + message. Tap Send test to me first, then Send.

Needs the newest send-notification.yml in your repo. Never share your token.
Your UID: Firebase → Database → fcmTokens → the key above your token.
